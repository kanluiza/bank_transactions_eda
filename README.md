📌 О проекте
Исследовательский анализ данных (EDA) на основе реальных банковских транзакций Сбербанка.
Главный вопрос: можно ли определить возраст клиента, зная только историю его покупок по карте — без анкет и личных данных?
Датасет предоставлен в рамках соревнования Sberbank Sirius на ODS.ai.
---
📊 Данные
Файл	Описание
`transactions_train.csv`	~27 млн транзакций: дата, сумма, категория, ID клиента
`train_target.csv`	30 000 клиентов с метками возрастной группы (0–3)
`small_group_description.csv`	Расшифровка 204 категорий транзакций
Ключевые поля:
`client_id` — уникальный номер клиента
`trans_date` — номер дня в хронологическом порядке (730 дней = 2 года)
`small_group` — категория транзакции (супермаркеты, аптеки, АЗС и т.д.)
`amount_rur` — сумма транзакции (анонимизирована без потери структуры)
`bins` — возрастная группа клиента (0, 1, 2, 3)
---
🔍 Что исследовалось
Распределение транзакций по дням недели и дням месяца в разрезе возрастных групп
Топ категорий по количеству транзакций и по объёму в рублях
Средний чек по категориям и по возрастным группам
Lift-анализ категорий — какие категории аномально популярны у конкретной возрастной группы
Динамика трат по месяцам за 2 года наблюдений
---
💡 Ключевые находки
1. Размер чека устойчиво различает группы
Иерархия среднего чека сохраняется в любой день недели, в любой месяц на протяжении всех 730 дней:
Группа	Возраст (оценка)	Средний чек	Трат в месяц
1	~46–55 лет	~75 руб.	18.52M руб.
3	~36–45 лет	~70 руб.	18.05M руб.
0	~26–35 лет	~52 руб.	13.97M руб.
2	~18–25 лет	~30 руб.	8.57M руб.
2. Категории трат — главный идентификатор возраста
Группа	Маркерные категории
2 — молодёжь (~18–25 лет)	видеоигры, кинотеатры, табак, каршеринг, онлайн-магазины, образование
0 — молодые (~26–35 лет)	детская одежда, игрушки, доставка еды, санатории
3 — зрелые (~36–45 лет)	нумизматика, благотворительность, краудфандинг, курсы, спорт
1 — средний (~46–55 лет)	мясо и морепродукты, декор, стройматериалы, мебель, авиабилеты
3. Что не помогает определить возраст
День недели — все группы ведут себя одинаково
Топ-категории по количеству — супермаркеты, фастфуд и телефония популярны у всех
Временной тренд — группы растут пропорционально
> Это тоже ценный результат: он говорит о том, какие признаки **менее полезны** для модели предсказания возраста.
4. Вывод для бизнеса
Клиентов банка можно сегментировать по возрасту без анкетных данных — только по истории транзакций. Достаточно трёх признаков:
Размер среднего чека
Доля трат в маркерных (lift) категориях
Соотношение частых и редких покупок
